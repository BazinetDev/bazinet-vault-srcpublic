First launch: this early build isn't notarized by Apple yet, so macOS may warn you the first time — right-click the app → Open to allow it. After that it launches normally and updates itself automatically, with every update signature-verified before it installs.

Why go native

Safer than a browser tab

Same encryption, same account, same zero-knowledge design — just a tougher shell around it.

Isolated from your browser

Runs in its own hardened window — not a tab. Malicious extensions and other sites can't reach into it.

Session in the Keychain

Your sign-in token lives in the macOS Keychain — never in browser storage or on disk in plaintext.

Same zero-knowledge vault

Encryption still happens on your device; the server only ever sees ciphertext. Nothing about that changes.

Signed auto-updates

Updates are verified against an embedded key before they install — a spoofed or tampered update is rejected.
