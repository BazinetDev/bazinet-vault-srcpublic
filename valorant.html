Built to be safe

Compliant by design

The core app gives no in-game advantage. Match analysis comes only from the official Riot Games API — Riot's servers, not the game client. The live overlay merely reads your running client locally, the same read-only mechanism public rank-trackers use. It never reads game memory, injects, hooks, or overlays the game process.

Integrated SnapTap / SOCD is not fully recognized by Riot Games

The app bundles an optional Snap Tap / SOCD movement toggle (powered by open-source SnapKey). Snap Tap was theoretically banned in Valorant (Riot, 2024) and using it can get your account suspended, but many people use it without any issues. It's disabled by default.

Questions

Frequently asked

Is this allowed by Riot / will it get me banned?

The core app is read-only and never touches the game process — match data comes from the official Riot API and the live view only reads your own running client, exactly like public rank-trackers. The single exception is the optional Snap Tap toggle, which is banned in Valorant and ships disabled; don't turn it on for Valorant.

Do I need a Riot API key?

No. You can enable the keyless "live client view," which analyzes your matches by reading your own logged-in client session — no production key required. A Riot API key is supported too.

What do I sign in with?

Your Bazinet account (the same one at bazinet.net). Sign-in happens in your browser with password, 2FA, passkey or Google — the app never sees your password.

Which platforms are supported?

Windows 10 and 11 (64-bit). The installer is signed for one-click install and updates itself automatically.

Does the overlay show live K/D and ults?

Riot no longer exposes live mid-match scoreboard stats through the client API, so the overlay focuses on what's available: map, round score, and both teams' agents and names.
